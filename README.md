# 🛰️ مدير المنصات · Social Platforms Manager

اكتب منشور واحد (نص، صورة، فيديو، أو صوت/موسيقى)، والنظام ينشره تلقائياً بكل المنصات، **وحدة وحدة**، ويعدّل
المنشور حسب كل منصة، وبالنهاية يكلك: **«🎉 انتشر في كل المنصات (7/7)»**.

| المنصة | شلون ينتشر |
|---|---|
| 💼 لينكدإن | Posts API: نص، صورة، فيديو (الصوت يتحول فيديو). الهاشتاكات تصير روابط حقيقية |
| 📘 فيسبوك (صفحة) | Graph API: منشور نصي مع رابط، صورة، فيديو |
| 📸 إنستغرام (حساب احترافي) | صورة، أو Reel للفيديو والصوت. النص يتحول **بطاقة صورة** تلقائياً |
| 🎵 تيك توك | Content Posting API: فيديو. الصورة والنص والصوت تتحول فيديو تلقائياً (ffmpeg) |
| ▶️ يوتيوب | YouTube Data API: فيديو، والصورة والنص والصوت تتحول فيديو عمودي (Short) مع عنوان ووصف وتاغات |
| ✈️ قناة تيليجرام | رسالة / صورة / فيديو / ملف صوت |
| 📰 مدونة الموقع | مدونة مدمجة على `/blog` مع RSS، جاهزة كموقع |
| 🌐 ووردبريس (اختياري) | REST API + Application Password |

## شلون تستخدمه

**من تيليجرام (البوت):** ارسل للبوت أي شي (نص، صورة، فيديو، موسيقى، فويس) ويا الوصف. يرجعلك معاينة وأزرار:
`🚀 انشر الآن بكل المنصات` · `🕒 جدولة` · `🎯 المنصات` (تختار وين ينتشر) · `👁 معاينة كل منصة` · `✏️ تعديل النص`
· `✨ صياغة بالذكاء الاصطناعي`. أثناء النشر رسالة وحدة تتحدث: ⏳ ← ✅ رابط المنشور / ❌ السبب، ولو فشلت منصة
يطلع زر `🔁 أعد المحاولة للفاشلة` (المنصات اللي نجحت ما ينعاد نشرها).
الأوامر: `/status` حالة كل المنصات · `/last` آخر المنشورات.

**من الداشبورد:** إحصائيات، حالة كل منصة، كتابة منشور ورفع ملف، تعديل نسخة كل منصة قبل النشر، الجدولة،
نتيجة كل منصة مع الرابط، والسجل.

## التعديل حسب المنصة (تلقائي)

- حدود الطول: لينكدإن 3000، إنستغرام وتيك توك 2200، تيليجرام 4096… يقص على حدود الكلمات.
- الهاشتاكات تنفصل وتنضاف لكل منصة بعددها المناسب (إنستغرام 15، لينكدإن 5، فيسبوك وتيليجرام 3، تيك توك 5).
- الرابط: يظل بلينكدإن/فيسبوك/تيليجرام، وبإنستغرام يصير «🔗 الرابط بالبايو» (إنستغرام ما يقبل روابط).
- المدونة: أول سطر يصير عنوان المقال والباقي متن المقال.
- **مع مفتاح Groq أو Gemini (مجاني):** يكتب نسخة بأسلوب كل منصة (رسمي للينكدإن، قصير وجذاب لتيك توك…).

## التشغيل

```bash
pip install -r requirements.txt     # + ffmpeg على السيرفر (لتيك توك والريلز)
python app.py                       # الداشبورد على http://localhost:5000 (أول دخول يحدد كلمة السر)
python worker.py                    # اختياري: بوت + نشر مجدول بدون cron (عملية شغالة دائماً)
python -m pytest -q                 # الاختبارات (بدون إنترنت)
```

إنستغرام وتيك توك يسحبون الملفات من رابط الموقع، فلازم الموقع يكون **منشور على HTTPS** (مو localhost).

### النشر على PythonAnywhere
1. Web ← Add a new web app ← Manual configuration (Python 3.10+).
2. `PA_USER=اسمك PA_TOKEN=التوكن ./deploy.sh` (التوكن من Account ← API token).
3. بكونسول PythonAnywhere: `pip install --user -r ~/spm/requirements.txt`
4. افتح الموقع، حدد كلمة السر، وروح لـ **ربط المنصات**.
5. للنشر المجدول: انسخ «رابط النشر المجدول» من الإعدادات وحطه كـ secret باسم `SPM_TICK_URL` بالريبو
   (GitHub Actions يفتحه كل 5 دقائق: `.github/workflows/tick.yml`)، أو شغّل `worker.py` كـ Always-on task.

> الحساب المجاني بـ PythonAnywhere يسمح فقط بمواقع معيّنة (whitelist). إذا منصة فشلت بخطأ Proxy/403،
> تحتاج حساب مدفوع أو VPS (Hetzner/Render/Railway…) وشغّل `gunicorn wsgi:application` + `python worker.py`.

## ربط المنصات (كلها من صفحة «ربط المنصات» وبيها الخطوات بالتفصيل)

- **تيليجرام:** بوت من @BotFather، ضيفه أدمن بالقناة، حط التوكن والقناة، واضغط «افتح البوت واربطه بحسابك»
  (رمز لمرة وحدة؛ بعدها البوت يسمع منك وحدك).
- **فيسبوك + إنستغرام:** تطبيق Business بـ developers.facebook.com، User Token من Graph API Explorer بالصلاحيات
  `pages_show_list, pages_manage_posts, pages_read_engagement, instagram_basic, instagram_content_publish, business_management`.
  مع App ID/Secret يتحول التوكن لتوكن صفحة **ما ينتهي**. حساب إنستغرام لازم يكون احترافي ومربوط بالصفحة.
- **لينكدإن:** تطبيق بـ linkedin.com/developers مع «Sign In with LinkedIn using OpenID Connect» و «Share on LinkedIn»،
  Redirect: `https://موقعك/oauth/linkedin/callback`. التوكن 60 يوم والداشبورد ينبهك قبلها.
- **تيك توك:** تطبيق بـ developers.tiktok.com مع Login Kit + Content Posting API، Redirect:
  `https://موقعك/oauth/tiktok/callback`. ⚠️ قبل ما تيك توك **يدقق** التطبيق، المنشورات تطلع **خاصة** بس
  (النظام يعيد المحاولة كخاص ويكلك). قدّم التطبيق للتدقيق حتى تصير عامة، أو اختار وضع «مسودة بالتطبيق».
- **يوتيوب:** مشروع بـ console.cloud.google.com مع YouTube Data API v3، OAuth client نوع Web application،
  Redirect: `https://موقعك/oauth/youtube/callback`، وخلي شاشة الموافقة **In production** (بوضع Testing الربط يخلص بعد 7 أيام).
  ⚠️ قبل ما Google يدقق المشروع، الفيديوهات تنرفع **خاصة** (النظام يكلك). قدّم على تدقيق YouTube API حتى تصير عامة.
- **ووردبريس:** Users ← Profile ← Application Passwords.

## البنية

```
app.py              الداشبورد، OAuth، webhook البوت، /tick، المدونة، روابط الملفات العامة
worker.py           بوت (polling) + ساعة النشر، لمن عندك عملية شغالة دائماً
spm/engine.py       دورة حياة المنشور والنشر وحدة وحدة + تقرير تيليجرام
spm/adapt.py        نسخة لكل منصة (قواعد + ذكاء اصطناعي اختياري)
spm/media.py        بطاقة النص، JPEG، تحويل صورة/صوت/نص لفيديو
spm/bot.py          بوت التحكم
spm/platforms/      منصة لكل ملف: linkedin, facebook, instagram, tiktok, youtube, telegram, blog, wordpress
data/               الإعدادات والتوكنات والمنشورات والملفات (خارج git)
```

إضافة منصة جديدة: ملف بـ `spm/platforms/` فيه `KEY, NAME, ICON, connected(), check(), publish()` وتضيفه لـ `ORDER`.
